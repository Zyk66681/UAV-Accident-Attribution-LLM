# 无人机对地事故标注与分类指南 (Annotation Guidelines)

本指南详细定义了多维联合归因与推断任务中，三大核心后果指标的分类边界。

## 1. 事故类型 (Accident Type)
根据致因主导机制，划分为以下 5 类：

* **人为因素主导型：** 由操作失误、注意力分散或应急处置不当直接引发。
* **设备故障型：** 由飞行控制系统故障、动力系统故障、通信链路故障、负载系统故障等系统失效导致。
* **环境干扰型：** 由气象环境干扰、地理环境干扰、电磁环境干扰类等外部环境扰动诱发。
* **管理缺失型：** 由资质管理缺失、空域管理缺失、设备管理缺失、应急管理缺失等所致。
* **复合型：** 由两类及以上因素耦合且无单一主导项导致。

## 2. 地面损害程度 (Ground Damage Extent)
依据《民用无人驾驶航空器事件信息管理办法》，划分为 4 级：

* **无损害：** 无人机坠毁于无人区，未造成任何人员伤亡、财产损失或环境影响。
* **轻微损害：** 仅造成轻微财产损失（如损坏围栏、屋顶瓦片、车辆漆面），或对地面人员造成非致命轻伤（如擦伤、惊吓），无需医疗介入。
* **中度损害：** 造成可修复的财产损失（如损坏电力设施、通信塔、窗户）或导致地面人员需医疗处理的受伤（如骨折、轻度烧伤），但无生命危险。
* **严重损害：** 导致人员死亡、重大财产损毁（如引发火灾、爆炸、关键基础设施瘫痪）或重大环境/社会影响（如坠入学校、医院、人群密集区）。

## 3. 伤亡人数 (Casualties)
为平衡稀疏性（长尾分布），采用区间化编码分为 3 类：
* **0人**
* **1-3人**
* **4人及以上**

## 附录：事故链重构与要素映射规范示例
**原始叙述 (Narrative)：** “无人机在执行巡逻任务时电量耗尽，坠落至树林中，造成机体损坏”。
**重构事故链：** 未制定续航冗余标准（管）→操作员未监控电池状态（人）→电池耗尽导致动力中断（机）→紧急着陆时撞击树木（环）→机体实质性损坏，无人员伤亡（后果）。
