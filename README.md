# 融合语义建模与大语言模型的无人机对地事故致因溯源方法
# Drone Ground Accident Causation Attribution Method

本项目为论文《融合语义建模与大语言模型的无人机对地事故致因溯源方法》的官方开源仓库。包含用于无人机事故多维推断的脱敏数据集，以及基于 SHAP（夏普利值）的可解释性归因验证代码。

## 📖 项目简介 (Introduction)
针对低空公共安全监管中非结构化事故文本难以直接支撑精准风险溯源的难题，提出一种融合语义建模与大语言模型参数高效微调的无人机对地事故自动归因方法。首先，构建以“人-机-环-管”四维风险要素为核心的语义映射机制，重构时序事故演化链，以解决非结构化文本特征稀疏与因果逻辑断裂问题。其次，基于Qwen-7B基座模型构建判别式多任务协同推断框架，结合量化低秩自适应（QLoRA）策略，在算力受限条件下实现事故类型、地面损害程度及伤亡人数的端到端同步推断。最后，引入基于夏普利值（SHAP）的可解释归因与语义表述鲁棒性验证机制，量化语义单元的边际贡献。基于1213条真实无人机事故记录的实验结果表明：该方法在事故类型与地面损害程度推断任务上的宏平均F1值分别达0.9250与0.9054；针对长尾分布的伤亡人数推断任务，F1值达0.4131；在仅激活0.23%可训练参数的前提下，训练显存峰值控制在12.52 GB。本研究揭示了多因素耦合归因中的“特征博弈”机制，实现了边缘算力约束下的可解释性语义风险感知，为低空运行风险动态预警与智能化事故调查提供了理论与技术支撑。

本仓库开源了研究中的核心数据集与验证评估代码，主要探讨了多因素耦合归因中的“特征博弈”机制，以期为低空运行风险动态预警与智能化事故调查提供技术参考。

## 📊 数据集说明 (Data Description)

本项目提供的数据来源于航空安全网（Aviation Safety Network, ASN）的历史记录，经过清洗与去重，共计 1213 条有效样本。

### 1. 原始数据 (`[drone_accidents_data].xlsx`)
包含了原始的非结构化事故叙述（Narrative）及部分基础元数据，反映了事故的真实演化过程。核心字段包括：事故发生时间、地点、机型、飞行阶段以及事故经过的自然语言描述。

### 2. 结构化数据 (`[merged_train_dataset_three_casualty_from_merged].xlsx`)
在原始数据基础上，通过语义建模抽取并重构的结构化数据，用于大模型的端到端训练与推断。包含：
* **致因要素**：“人-机-环-管”四维特征向量。
* **事故链演化逻辑**：标准化的时序事故链描述。
* **多维后果标签**：
    * 事故类型（5类：人为因素主导型、设备故障型等）
    * 地面损害程度（4类：无损害、轻微损害等）
    * 伤亡人数（3类区间化编码）

## 💻 代码说明 (Code Description)

**`[shap_robustness_stability].py`** 实现了论文中提出的**归因特征可解释性机制**。

为了提升大模型在安全关键任务中的决策透明度，该代码利用基于句子掩码扰动（Sentence Masking Perturbation）的 SHAP 近似方法，量化输入语义单元（句子级与词语级）对多维协同推断置信度的边际贡献。
* **功能 1**：计算句子级特征贡献度，验证模型对主导致因的判断逻辑。
* **功能 2**：滑动窗口掩码扰动，定位词语级关键风险词元（如“耗尽”、“未监控”等）。
